# ATHLEIRON Brand Guidelines

## Brand Essence

**Name:** ATHLEIRON  
**Tagline:** Engineered for Athletes. Built to Last.  
**Positioning:** Premium UK-designed sportswear that balances performance, durability, and accessible pricing.

## Target Audience

- UK-based fitness enthusiasts, gym-goers, and athletes
- Ages 18–40
- Values quality, durability, and clean athletic style
- Willing to invest in gear that outlasts fast-fashion alternatives

## Logo

The ATHLEIRON logo consists of:
- An angular "A" icon inside a rounded square (flame/orange on dark)
- Wordmark: **ATHLE** in white + **IRON** in flame orange

### Files
- `public/logo-icon.svg` — Icon only
- `public/favicon.svg` — Favicon
- `src/components/Logo.jsx` — React component

## Colour Palette

| Role | Hex | Usage |
|------|-----|-------|
| Dark background | `#0a0a0b` | Page background |
| Dark cards | `#171718` | Cards, panels |
| Border/dividers | `#2e2e31` | Borders, separators |
| Muted text | `#9a9aa3` | Secondary text |
| Primary accent | `#ff4d00` | CTAs, highlights, links |
| White | `#ffffff` | Headings, primary text |

## Typography

- **Primary font:** Inter (Google Fonts)
- **Weights used:** 400, 500, 600, 700, 800, 900
- **Headings:** Bold, tight tracking
- **Body:** Regular/medium weight, readable line height

## Tone of Voice

- Confident but not arrogant
- Performance-focused
- Direct and clean
- Encouraging and athletic

## Imagery Style

- Athletic, high-contrast photography
- Focus on movement, strength, and determination
- Dark, moody grading with orange accent lighting
- Real athletes, real gyms, real effort

## Key Messages

- Durability guaranteed
- Performance fabrics
- UK-designed
- Responsible manufacturing
- No compromises
